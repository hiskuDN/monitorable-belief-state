# lieworld writeups — the language / deception rung

model is induced to state something false, is the true belief still linearly recoverable, and does
predict-ahead training make it more so? The language-flavored, deception-surfaced extension of the
class-level monitorability claim (see [`../../safety-task-menu.md`](../../safety-task-menu.md) tasks
